# Self-hosted interface fonts

These webfonts are pinned to Fontsource 5.3.0 so production and CI builds do not
depend on a third-party font request:

- Inter
- Barlow Condensed
- IBM Plex Mono

All three families are distributed under the SIL Open Font License 1.1. The
upstream license and family metadata are available from
<https://fontsource.org/fonts>.
